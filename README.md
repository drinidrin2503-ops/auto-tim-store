# АвтоТим

Учебный прототип интернет-магазина автозапчастей на Flask, SQLite, HTML, CSS и JavaScript. Оплата на сайте не подключена: клиент оформляет заказ, после чего с ним связывается менеджер.

## Возможности

- Главная страница с категориями и рекомендованными товарами.
- Каталог с поиском и фильтрами по категории, бренду и цене.
- Страницы товара, корзина и оформление заказа.
- Панель администратора для добавления и удаления товаров.
- SQLite создаётся автоматически при первом запуске, в базу добавляются демонстрационные товары.

## Локальный запуск в Windows PowerShell

```powershell
cd C:\path\to\auto_team
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Перед запуском задайте секрет приложения и учётные данные администратора в текущей сессии PowerShell. Не отправляйте файл `.env` в GitHub:

```powershell
$env:FLASK_SECRET_KEY = (python -c "import secrets; print(secrets.token_hex(32))")
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD = "Укажите-длинный-уникальный-пароль"
python app.py
```

После запуска сайт доступен по адресу <http://127.0.0.1:5000>, панель входа — <http://127.0.0.1:5000/admin/login>.

Для входа обязательно задайте `ADMIN_USERNAME` и `ADMIN_PASSWORD`. Если они не заданы, вход в панель администратора отключён. При отсутствии `FLASK_SECRET_KEY` приложение создаёт случайный временный ключ при старте; для постоянной работы задайте свой ключ в окружении и храните его в секрете хостинга, а не в репозитории.

## GitHub

Перед первым коммитом проверьте `git status`: локальная база `autotim.db`, виртуальное окружение `.venv` и секреты `.env` должны быть исключены файлом `.gitignore`. Репозиторий с исходным кодом безопаснее сначала создать приватным. Для публикации самого сайта понадобится отдельный хостинг с поддержкой Flask и постоянным хранилищем SQLite.

## Фотографии категорий

Фотографии категорий находятся в `static/images/categories/`. Источники, авторы и лицензии указаны в раскрываемом блоке «Источники фотографий и лицензии» на главной странице.
